# 网页设置工作区与新对话模型

在 Code 新会话底部点击目录按钮，可浏览运行端文件夹，或输入完整路径并按 Enter。目录读取成功后显示规范路径和信任状态。未信任目录需要先勾选说明，再点击「信任此目录」。授权保存到运行端现有的项目配置，只覆盖所显示目录及其子目录；切换到其他目录仍需单独确认。文件、不可读取路径和发生变化的目录别名不会获得信任。普通创建会话请求仍拒绝未信任目录。

这与终端中的工作区信任含义一致：项目文件、配置、命令可在所选工具权限范围内使用。工作区信任不会改变会话的工具权限模式。

Chat 首页的「新对话模型」下拉框可选择该运行环境中启用且未验证失败的模型；选择「沿用 CLI 默认模型」会保留既有默认行为。若没有可选项，点击「添加或验证模型」进入供应商设置。所选模型只用于新建对话，不改全局默认，也不改已有对话。首条消息在模型激活成功后发送；激活失败会显示错误并保留首条消息，不会静默使用其他模型。

更新后需要重新构建网页并重启 RCS 与 Worker，已有运行进程不会自动加载改动。
